# Бот дней рождения

Telegram-бот для сотрудников и партнёров компании. Доступ только по приглашениям, черновики поздравлений сотрудникам генерирует Claude и проверяет HR, публикация идёт в прикреплённые группы, менеджерам приходят напоминания о партнёрах.

## Запуск

1. Создайте бота в @BotFather и получите токен.
2. Скопируйте `.env.example` в `.env`, заполните `BOT_TOKEN`, `ADMIN_IDS` и `ANTHROPIC_API_KEY`.
   Свой ID можно узнать после запуска командой `/id`.
3. Перенесите старую базу (в репозитории её нет — там персональные данные):
   `python migrate.py birthday_calendar.db data/birthdays.db`
   Скрипт склеит ответственных, поправит отделы и напечатает, что проверить руками.
4. Запустите: `docker compose up -d --build`, логи: `docker compose logs -f`.

**Где держать сервер.** Claude API не принимает запросы из России. Запускайте бота на зарубежном VPS или пропишите `ANTHROPIC_PROXY`. Если API недоступен, бот не падает, а пишет поздравления по шаблону.

## Роли

| Роль | Что может |
|---|---|
| Администратор | всё: доступы, группы, настройки, все карточки, получает эскалации |
| HR | сотрудники и партнёры, модерация поздравлений, группы, экспорт |
| Менеджер | только свои партнёры: видит, добавляет, отмечает «поздравил» |

**Приглашение:** «👥 Доступы» → человек (или «➕ Пригласить») → «🔗 Ссылка-приглашение» → переслать.
Ссылка одноразовая и действует 7 дней. Ответственные из старой базы заводятся при переносе как менеджеры без Telegram. Как только человек перейдёт по ссылке, к нему привяжутся его партнёры.

## Как это работает

**Сотрудники**
- За 7 дней HR получает напоминание (там же видно, что положено, например премия) и может заранее написать характеристику.
- Накануне в 09:00 HR получает черновик с кнопками «Отправить», «Другой вариант», «Свой текст», «Характеристика», «Не публиковать».
  Если характеристики нет, бот сначала просит 1–2 предложения о человеке.
- В сам день в 10:00 текст уходит в группу. Если HR ничего не нажал, публикуется черновик. Если HR нажал «Не публиковать», ничего не уходит.
- В карточке можно выключить публичное поздравление для конкретного человека (флаг «не поздравлять публично»).

**Партнёры**
- Ответственному приходят напоминания за 7 дней, за день и в сам день. Кнопки: «✍️ Текст поздравления» (Claude пишет личное сообщение) и «✅ Поздравил» (с выбором способа).
- В 18:00 админы получают список партнёров, которых сегодня не отметили.
- Если ответственный ещё не подключён, напоминание приходит админам.

**Группы:** добавьте бота в группу со своего аккаунта (админ или HR), и он прикрепится сам. Если бота добавит посторонний, он выйдет из группы. В «💬 Группы» можно назначить отделы для каждой группы.

**Планировщик** запоминает в базе, что уже сделано. Если бот перезапустить, пропущенные задачи выполнятся, а повторных отправок не будет.

## Что проверить после переноса

`migrate.py` печатает отчёт: склеенные варианты ответственных, исправленные отделы, сотрудников без отдела, партнёров с одинаковыми именами. Пройдитесь по нему перед запуском.
